## 01. 장부 두 방향 (`01-ledger-directions-a-b.html`)

공통 규칙: **"흑자/적자"라는 말이 검은 글씨/붉은 글씨에서 나왔다는 데서
착안** — 수입엔 별도 색을 안 주고 지출만 붉은 잉크로 표시. 카드 대신
괘선으로 구획.

- **방향 A — 초록 괘선 장부** (라이트): 회계장부 괘지 + 왼쪽 붉은 여백선
- **방향 B — 분필 칠판 장부** (다크): 슬레이트 배경 + 점선 괘선, 블러·그라데이션 없음

→ **A안 채택**

## 02. 완전히 다른 컨셉 5가지 (`02-other-concepts.html`)

"장부"라는 틀 자체를 벗어나 가계부를 다른 사물로 재해석:

1. **영수증** — 감열지는 흑백이라는 데서 착안, 색 없이 굵기·기호로만 구분
2. **에어메일** — 항공우편 봉투의 적청 사선 테두리, 우표 소인
3. **저금통** — 테라코타 톤, 원(둥근 모양)은 진짜 동전이 필요한 곳에만
4. **통장** — 색 대신 출금/입금 "칸 위치"로 의미 구분, 줄마다 잔액 표시
5. **고지서** — 공과금 명세서 느낌, 박스형 숫자 필드 + 붉은 승인 도장
