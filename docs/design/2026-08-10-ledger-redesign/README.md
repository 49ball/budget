# UI 재설계 탐색 — 2026-08-10

기존 다크+보라 팔레트를 다크+황동(`3995fdb`)으로 재칠했다가 "틀 자체가
AI스럽다"는 피드백을 받고 반려. "단일 액센트색 변수 + 유리블러 카드"라는
구조 자체를 벗어나는 방향으로 다시 탐색한 기록.

## 01. 장부 두 방향 (`01-ledger-directions-a-b.html`)

공통 규칙: **"흑자/적자"라는 말이 검은 글씨/붉은 글씨에서 나왔다는 데서
착안** — 수입엔 별도 색을 안 주고 지출만 붉은 잉크로 표시. 카드 대신
괘선으로 구획.

- **방향 A — 초록 괘선 장부** (라이트): 회계장부 괘지 + 왼쪽 붉은 여백선
- **방향 B — 분필 칠판 장부** (다크): 슬레이트 배경 + 점선 괘선, 블러·그라데이션 없음

→ 이 시점엔 A안 채택. (이후 02에서 통장으로 최종 변경, 아래 참고)

## 02. 완전히 다른 컨셉 5가지 (`02-other-concepts.html`)

"장부"라는 틀 자체를 벗어나 가계부를 다른 사물로 재해석:

1. **영수증** — 감열지는 흑백이라는 데서 착안, 색 없이 굵기·기호로만 구분
2. **에어메일** — 항공우편 봉투의 적청 사선 테두리, 우표 소인
3. **저금통** — 테라코타 톤, 원(둥근 모양)은 진짜 동전이 필요한 곳에만
4. **통장** — 색 대신 출금/입금 "칸 위치"로 의미 구분, 줄마다 잔액 표시
5. **고지서** — 공과금 명세서 느낌, 박스형 숫자 필드 + 붉은 승인 도장

→ **통장 최종 채택**, 실제 `index.html`에 구현됨 (`95702a8`)

## 03. 통장 × 저금통 조합안 (`03-passbook-coin-hybrid.html`)

통장의 색감·구조는 그대로 두고, 저금통에서 "저장 시 동전이 슬롯에
떨어지는" 인터랙션만 가져와본 시안. 실제로 클릭해서 동전이 떨어지는
걸 볼 수 있음.

→ **반려.** 동전이 슬롯 속으로 사라지는 느낌이라 "쌓인다"보다
"없어진다"에 가까워 보였음.

## 04. 저장 효과 대안 3가지 (`04-save-effect-alternatives.html`)

동전 오브젝트를 빼고 다른 방식으로 "저장됐다"는 확인을 주는 3가지 시안:

1. **잔액 숫자 롤업** — 계산기처럼 숫자가 이전 값에서 새 값으로 굴러감
2. **통장 임팩트** — 저장 순간 통장 전체가 살짝 흔들림
3. **초록 잉크 도장** — 예전 금색 도장을 통장 초록색으로 재작업

→ **1번(숫자 롤업) 채택**, `index.html`에 구현 (`95702a8`). 처음엔
화면 아래 "지출: N원" 배지를 굴렸는데 저장 버튼에서 너무 멀어 안
보이는 문제가 있어서, 저장 버튼 바로 아래에 미니 표시를 추가하고
